# Модель системной динамики ДТС мегаполиса

Интерактивный калькулятор по статье «Модели системной динамики для управления дорожно-транспортной системой мегаполиса» (Цвиркун А.Д. и др.).

Приложение считает динамику 13 показателей дорожно-транспортной системы, строит графики, проверяет ограничения и рассчитывает функционал потерь \(Z\).

Публичная версия:

**https://atmega-p471.github.io/road-safety/**

---

## Что подаётся на вход

### 1. Входные данные всей модели

| Что | Обозначение | Где задаётся |
|---|---|---|
| Начальные условия | \(X_1(0)\ldots X_{13}(0)\) | таблица «Начальные условия» на вкладке «Прогноз» |
| Коэффициенты 76 функций | \(c_3,c_2,c_1,c_0\) для \(f_1\ldots f_{76}\) | левая панель «Кубические функции» |
| Коэффициенты 6 факторов | \(d_3,d_2,d_1,d_0\) для \(E_1\ldots E_6\) | низ левой панели |
| Нижняя граница коридора | \(X_{\min}\) | строка «Параметры» |
| Верхняя граница коридора | \(X_{\max}\) | строка «Параметры» |
| План | \(p_1\), \(p_2\), \(p_3\) | вкладка «Планы» |
| Цели показателей | \(X_i^*\) | вкладка «Радар» |
| Веса показателей | \(w_i\) | вкладка «Радар» |

Важно:

- \(X_{\min}\) и \(X_{\max}\) **не меняют решение дифференциальных уравнений**. Они нужны только для проверки ограничения (3), подсветки нарушений и границ графика.
- Цели \(X_i^*\) и веса \(w_i\) **не влияют на RK4**. Они используются только при расчёте \(Z\).
- Шаг \(h=0.125\) и нормировка \(19.05\) в обычном режиме фиксированы.
- В режиме «Демо-синус» шаг уменьшается до \(0.005\), а нормировка меняется на \(80\).

### 2. Вход одного шага Рунге–Кутты

На каждом шаге функция `computeDerivatives(t, X, params)` принимает:

| Аргумент | Что это |
|---|---|
| `t` | текущее время, число от 0 до 1 |
| `X` | массив из 13 чисел — текущие значения \(X_1\ldots X_{13}\) |
| `params` | режим расчёта: план, нормировка, параметры демо-воздействия |

Внутри шага используются:

- `funcs76` — коэффициенты 76 кубических функций;
- `E_FACTORS` — коэффициенты 6 внешних факторов;
- `EQ_LINKS` — связи «какая функция входит в какое уравнение».

На выходе одного шага — массив из 13 чисел:

\[
\left[\frac{dX_1}{dt},\ldots,\frac{dX_{13}}{dt}\right]
\]

То есть на вход подаются **время, текущее состояние и коэффициенты**, а на выходе получаются **скорости изменения всех 13 показателей**.

### 3. Входные данные для `solveSystem`

Функция `solveSystem(params)` принимает объект:

| Поле | Смысл |
|---|---|
| `initial[13]` | начальные значения \(X_i(0)\) |
| `h` | шаг интегрирования |
| `densePerStep` | число точек сгущения между узлами RK4 |
| `plan` | `p1`, `p2` или `p3` |
| `norm` | нормировочный коэффициент |
| `sineAmp` | амплитуда периодического демо-воздействия; 0 — выключено |
| `sineFreq` | частота демо-воздействия |

## Что получается на выходе

### 1. Выход `solveSystem`

| Поле | Размерность | Что содержит |
|---|---|---|
| `tArr` | 9 значений | время в узлах RK4: `0, 0.125, …, 1` |
| `series` | 13 × 9 | значения \(X_i\) в узлах RK4 |
| `derivs` | 13 × 9 | производные \(dX_i/dt\) в узлах |
| `dense` | 13 × 129 | сглаженные кривые для графиков |
| `fittedPolys` | 13 объектов | квадратичные приближения \(X_i(t)\) для расчёта \(Z\) |
| `diverged` | boolean | признак расходимости решения |

В режиме «Демо-синус»:

- `tArr` — 201 узел;
- `dense` — 1601 точка.

### 2. Что считается дальше

| Результат | Где считается |
|---|---|
| Функционал \(Z\) | `computeObjective()` |
| Проверка ограничения \(X_{\min}\le X_i\le X_{\max}\) | `checkBounds()` |
| Близость к целям \(X_i^*\) | `targetStats()` |
| Значения для трёх планов \(p_1,p_2,p_3\) | `runAllCalculations()` |

### 3. Что видит пользователь

- графики \(X_i(t)\);
- значения \(X_i\) в конце горизонта;
- статус ограничений;
- значение \(Z\) и отклонение от статьи;
- таблицу планов;
- CSV с результатами.

CSV содержит **9 узлов RK4**, а не 129 точек графика. В первой строке CSV при `t=0` должны стоять заданные \(X_i(0)\).

## Как устроен расчёт

```
ввод данных
   ↓
runAllCalculations()
   ↓
solveSystem()  — метод Рунге–Кутты 4-го порядка
   ↓
computeDerivatives()  — правая часть dX/dt
   ↓
computeObjective()  — расчёт Z
   ↓
графики Chart.js + CSV
```

Метод Рунге–Кутты реализован вручную в `script.js`:

\[
X_{n+1}=X_n+\frac{h}{6}(k_1+2k_2+2k_3+k_4)
\]

Где:

- \(k_1\) — производные в начале шага;
- \(k_2\) — производные в середине шага по \(k_1\);
- \(k_3\) — производные в середине шага по \(k_2\);
- \(k_4\) — производные в конце шага по \(k_3\).

После RK4 решение сгущается кубическим Эрмитом до 129 точек, чтобы графики были гладкими.

## Как проверить работу в интерфейсе

1. Открыть вкладку **«Прогноз»**.
2. Раскрыть **«Начальные условия интегрирования»**.
3. Задать, например, \(X_1(0)=0.50\).
4. Нажать **«Экспорт CSV»**.
5. Проверить, что в первой строке данных при `t=0` стоит `0.50000`.

Также можно:

- изменить коэффициент \(c_0\) у \(f_1\) и посмотреть, как сдвинется кривая \(X_1\);
- изменить \(E_3\) и посмотреть, как изменится динамика;
- выбрать другой план \(p_2\) или \(p_3\);
- сравнить график с CSV.

## Демо-режимы

В левой панели есть три демонстрационные кнопки.

| Кнопка | Что делает |
|---|---|
| **Демо f(x)** | меняет коэффициенты функций; кривые становятся нелинейными, остаются в 0…1 |
| **Демо X(0)** | меняет начальные условия; функции и \(E\) не трогает |
| **Демо-синус** | добавляет периодическое воздействие \(0.2\sin(2\pi\cdot2t+\varphi_i)\); кривые похожи на синусоиды и остаются в 0…1 |

«Демо-синус» — это **демонстрация с внешним периодическим воздействием**, а не свободные колебания статьи. Собственный период колебаний модели около 90, а горизонт равен 1, поэтому без внешнего воздействия синусоиду на этом горизонте не видно.

Все демо-режимы можно сбросить кнопкой **«Сброс»**.

## Ограничения модели

- Это модель первого порядка; для появления собственных колебаний нужны комплексные собственные значения с достаточно большим мнимым части.
- Период собственной колебательной моды около 90, поэтому на горизонте \(0\ldots1\) она практически не видна.
- «Демо-синус» добавляет внешнее периодическое воздействие и не является данными статьи.
- Произвольная подстановка коэффициентов может увести \(X_i\) за пределы 0…1; это не ошибка расчёта, а свойство выбранных коэффициентов.
