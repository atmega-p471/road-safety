# Модель системной динамики ДТС мегаполиса

Интерактивный веб-калькулятор по статье Цвиркуна А.Д., Богомолова А.С., Дранко О.И. и др. «Модели системной динамики для управления дорожно-транспортной системой мегаполиса».

## Что внутри

- 13 показателей безопасности \(X_1 \ldots X_{13}\), 76 кубических функций \(f_1 \ldots f_{76}\) и 6 внешних факторов \(E_1 \ldots E_6\).
- Численное решение системы дифференциальных уравнений методом Рунге–Кутты 4-го порядка (шаг \(h = 0.125\)).
- Целевая функция \(Z(p)\), ограничение \(X_i \in [X_{min}; X_{max}]\), планы \(p_1, p_2, p_3\).
- Индивидуальные цели \(X_i^*\) и веса важности показателей в \(Z\); границы \(X_{min}\), \(X_{max}\) задаются отдельно.
- Вкладки: прогноз, радар, регрессии, коррекция, планы.
- Выбор показателей для графика, авто-зум по Y, экспорт CSV.
- Режим «Отклонение, %» и кнопки «Демо f(x)» / «Демо X(0)» / «Демо-синус» — показать изгибы и колебания, не выходя за 0…1.
- Начальные условия X(0) можно редактировать в таблице.
- Справочник формул и краткое описание исправлений.

## Как открыть

Открыть `index.html` в браузере. Для подгрузки Chart.js, Tailwind CSS и MathJax нужен интернет (библиотеки подключены через CDN).

Либо запустить локальный сервер:

```bash
python -m http.server 8000
```

и открыть <http://127.0.0.1:8000/>.

## Файлы

- `index.html` — интерфейс;
- `script.js` — модель, расчёты и графики;
- `style.css` — стили;
- `ИСПРАВЛЕНИЯ.md` — что было исправлено в расчётах и графиках.
